# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MCP Agent Factory, please report it
**privately** — do not open a public issue.

**Email:** [luca.flammia@gmail.com](mailto:luca.flammia@gmail.com)

Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The affected version(s) or commit hash

You can expect an initial acknowledgement within 72 hours. Fixes for confirmed
vulnerabilities will be released as soon as practical, with credit to the
reporter (unless you prefer to remain anonymous).

## Scope

This policy covers the `mcp-agent-factory` codebase and its Docker Compose
infrastructure configuration. Third-party dependencies are out of scope but
will be forwarded to the relevant upstream maintainers.

## Supported Versions

Only the latest release on the `main` branch receives security fixes.
